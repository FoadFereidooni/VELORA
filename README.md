# VELORA | فروشگاه اینترنتی پوشاک

**VELORA** یک وب‌سایت فروشگاهی مدرن برای نمایش و خرید محصولات پوشاک است که با استفاده از React، TypeScript و Tailwind CSS طراحی و پیاده‌سازی شده است.

این پروژه با طراحی مینیمال، رنگ‌بندی کرم و بژ و رابط کاربری فارسی، تجربه‌ای ساده و جذاب برای کاربران فراهم می‌کند.

## ✨ امکانات پروژه

- طراحی کاملاً فارسی و راست‌چین (RTL)
- رابط کاربری واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- صفحه اصلی با نمایش محصولات
- صفحه فروشگاه و دسته‌بندی محصولات
- جست‌وجوی محصولات
- فیلتر محصولات بر اساس دسته‌بندی
- مرتب‌سازی محصولات
- مشاهده جزئیات هر محصول
- انتخاب سایز محصول
- افزودن و حذف محصولات از سبد خرید
- مدیریت تعداد محصولات در سبد خرید
- لیست علاقه‌مندی‌ها
- نمایش محصولات اخیراً مشاهده‌شده
- قابلیت مشاهده سریع محصولات (Quick View)
- راهنمای انتخاب سایز
- صفحه درباره ما
- صفحه تماس با ما
- ذخیره اطلاعات سبد خرید و علاقه‌مندی‌ها در مرورگر با استفاده از Local Storage
- نمایش قیمت‌ها با قالب‌بندی فارسی

## 🛠️ تکنولوژی‌های استفاده‌شده

- **React** برای ساخت رابط کاربری
- **TypeScript** برای توسعه ساختاریافته‌تر و مدیریت نوع داده‌ها
- **Tailwind CSS** برای طراحی و استایل‌دهی
- **Lucide React** برای آیکون‌ها
- **Local Storage** برای ذخیره‌سازی اطلاعات در مرورگر

## 🚀 نصب و راه‌اندازی

ابتدا مخزن پروژه را کلون کنید:

```bash
git clone YOUR_REPOSITORY_URL
```

وارد پوشه پروژه شوید:

```bash
cd velora
```

سپس وابستگی‌های پروژه را نصب کنید:

```bash
npm install
```

در نهایت، پروژه را در حالت توسعه اجرا کنید:

```bash
npm run dev
```

پس از اجرا، آدرس نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.

## 📁 ساختار و بخش‌های پروژه

پروژه شامل بخش‌های مختلفی برای ارائه تجربه خرید آنلاین است:

- `App`: ساختار اصلی برنامه
- `Home`: صفحه اصلی
- `ProductCard`: کارت نمایش محصول
- `Shop`: صفحه فروشگاه
- `ProductDetail`: جزئیات محصول
- `Cart`: سبد خرید
- `Wishlist`: لیست علاقه‌مندی‌ها
- `About`: صفحه درباره ما
- `Contact`: صفحه تماس با ما
- `Footer`: بخش پایینی وب‌سایت
- `QuickView`: نمایش سریع اطلاعات محصول
- `SizeGuide`: راهنمای انتخاب سایز

## ⚠️ نکات مهم

- اطلاعات محصولات به‌صورت نمونه و در داخل پروژه تعریف شده‌اند.
- اطلاعات سبد خرید، علاقه‌مندی‌ها و محصولات اخیراً مشاهده‌شده در Local Storage مرورگر ذخیره می‌شوند.
- این پروژه در نسخه فعلی به بک‌اند یا پایگاه داده متصل نیست.
- سیستم ثبت‌نام و ورود کاربران و درگاه پرداخت آنلاین در آن پیاده‌سازی نشده است.
- فرم‌های تماس با ما و عضویت در خبرنامه در حال حاضر جنبه نمایشی دارند و به سرویس ارسال اطلاعات متصل نیستند.
